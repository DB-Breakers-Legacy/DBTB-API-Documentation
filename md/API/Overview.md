## API

### Overview

Two API servers are been used for the game.

| Service name | id | Domain name |
| --- | --- | --- |
| User/System API | 000000 | cosmos.channel.or.jp |
| Game API | 025348 | dbtb-prd.cosmos.channel.or.jp |

The User System API services is for mostly basical API functionality that all Bandai Namco games are using.
And the Game API services is been used for specificly "Dragon ball - The breakers"
